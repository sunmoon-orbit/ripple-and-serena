# 阅读器批注卡与翻页修复

2026-09-22：翻页模式点击划线，在当前页打开批注卡。再次点击划线、关闭按钮或卡片外区域收起，保留阅读模式和页码。支持从卡片生成书摘卡；滚动模式原批注列表保留。

分页位移改用实际视口宽度，多栏保持单栏宽度与视口同步。拖动或长按后抑制合成点击，避免菜单意外收放重新排页；取消触摸清除手势状态，多指、选字、长按不触发翻页，章节加载时阻止重复翻页。

35 项 Node 测试与正式构建通过。隔离 Chromium 使用虚构书籍验证打开和关闭批注后仍为翻页模式、位移不变，并验证下一页位移等于实际视口宽度。Android 原生长按手柄的完整手感仍以手机实际使用为准。
