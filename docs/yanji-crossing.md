# 言叽·渡口（第一阶段）

渡口是 Murmur 侧栏里的独立 Codex Agent 页面，不会替换言叽原来的 API 聊天。先在「拾羽」配置原有的记忆库连接，再从 Murmur 左侧栏点「渡口」。

## 拾羽 Token 解锁

在 **Hollow → 设置 → 拾羽记忆库** 启用记忆库，填写现有 Base URL 和 API Token，并测试连接。渡口复用这一份 Token，不新增密码。「前往设置」直接打开该区域。未启用、无效或未验证时，渡口保持锁定，不读取模型、用量或会话；刷新和重连也先验证再显示内容。

原 Token 延续现有浏览器 `llm_hub_state_v1` localStorage 保存方式；这是现状，不是安全保险箱。不要向他人分享站点存储或含凭据的备份。服务端不会把自己的 Token 回传浏览器。渡口验证后使用仅在内存中存在、最长 15 分钟且绑定当前 WebSocket 的短期凭证；清空／修改配置、验证失败、断线或到期即失效。服务器 Token 轮换后，旧会话在下次请求或定期检查时被撤销。已撤销连接的附件不能被新连接复用，需要重新上传。

附件、朗读和渡口内嵌的记忆库工具都经过短期会话鉴权；保留全部原工具入口。钱包仍使用原本地数据；通话与占卜仍跳转／提示在 Murmur 使用，不是 Codex 原生能力。原 Murmur API 聊天和归巢的鉴权独立保留。

## 主动联系开关

时间感知只为正常对话提供时间上下文，**不代表同意主动消息或主动电话**。两项独立开关均关闭时不允许主动联系；仅开电话时可以来电，但未接后不补发留言；仅开消息时不创建来电。

关闭设置会使服务端未投递队列失效，已发生的历史记录保留。生成前、入队前和最终投递前再次检查开关及持久版本，旧任务不能因稍后重新开启而复活。离线修改若同步失败会显示提示；应恢复网络后重试，浏览器不能在离线时更改服务器的实际开关。

已有留言气泡中的音频播放器并不代表已经合成音频：现有 Murmur 朗读由用户点击触发。主动消息生成与主动来电门禁不会禁止用户主动朗读历史消息或主动拨打原 API 通话。

## 能做什么

- 新建、列出、切换和恢复 Codex 持久会话。
- 流式显示 Codex 回复、工作项和上下文压缩提示。
- 显示 Codex 的 5 小时与 7 天用量；优先走 App Server，旧版本才标为「快照」。
- 在手机上对命令执行或文件修改选择「允许本次」或「拒绝」。授权严格绑定当前浏览器、会话、turn、工作项和请求编号；离开页面会自动拒绝待授权并中断该页面发起的任务。
- 用停止按钮中断当前 Codex turn。

`/new`、`/sessions`、`/resume <会话编号>` 是渡口本地快捷操作，不会作为普通消息发送给模型。

`/model` 打开模型面板。候选、显示名称、推理强度和图片能力来自当前账号的 `model/list`，分页读取并排除 hidden 模型。顶部只显示服务端确认的 model / reasoningEffort；没有确认时显示「模型未知」，不采用模型在聊天中的自述。面板选择用于新建会话；已有会话点击「应用到当前会话」执行 `thread/resume` 的局部 model/config override，下一轮显式携带 model/effort。若服务端尚未应用选择，会保留当前确认值并显示待应用状态。模型切换 warning 只显示一次，不手动重复插入切换指令。

0.153.4 的 `thread/start` 和 `thread/resume` 没有独立 effort 参数，使用局部 `config.model_reasoning_effort`；`turn/start` 使用 `effort`。渡口选择保存在 bridge 专用忽略文件中，重连／重启后恢复，不调用 `config/value/write`，不改服务器全局默认模型。`thread/read` 的 model/effort 是配置或最近持久值，并非逐轮执行遥测。

图片／文件入口与 Murmur 共用选择器和图片压缩逻辑。渡口图片支持 JPEG、PNG、WebP、GIF（原文件最大 4MB，压缩后上传）；服务器复用 `/raven/upload?channel=crossing` 和记忆库鉴权，校验扩展名、MIME、文件签名与大小，以随机名称保存在工作目录专用 `.crossing-uploads/` 中，仅返回附件 ID。服务端将 ID 转换为 `localImage`，不会把临时绝对路径发给浏览器。附件最多四个，一小时后自动清理；正在执行的附件暂缓清理。服务重启后待发附件需要重新添加。

表情包使用与 Murmur 相同的内置和自定义选择器。已知公开贴图库的无凭证 HTTPS URL 使用稳定 `image` 输入；其他自定义链接仍显示在选择器中，但需下载后通过图片入口上传。模型未确认或不支持 image 时图片与表情包入口禁用。

普通文件支持 UTF-8 的 txt/md/csv/json/js/py/html/css，最大 200KB，真实保存在同一受限目录；turn 的文本输入提供相对路径供 Codex 在工作目录读取。PDF、Office、压缩包、二进制暂不支持，会明确报错。历史附件过期后不能保证再次读取，请重新添加。

工具入口全部保留：今日小票、身体气象站、便利贴墙、涟言点的歌、乌鸦钱包、游戏室、小月历、卡册、独处手账直接复用现有组件与执行链路；钱包为本机存储。语音通话、通话记录、幸运轮盘、命运牌阵、塔罗、今日签保留入口并提示前往 Murmur。通话记录涉及原聊天跳转；通话和占卜相关流程本次不新增 Codex 适配。这些是用户手动工具，不代表 Codex 已获得调用它们的能力。

点右上角「＋」新建后会自动选中；点「会话」展开纵向列表，选择历史会话会先读取再恢复，显示「会话就绪」后才可发送。连接成功但未选会话时发送按钮保持禁用。网络重连后会重新恢复当前会话；恢复失败时可重新选择或新建，错误可关闭。列表包含本项目目录的渡口（appServer）、CLI 和 VS Code 会话。

手机输入框从一行开始，最多增长到 120px；发送／停止按钮至少 64×44px。历史会话标题最多显示两行，工具输出默认折叠。

渡口现在会在本机保存 Murmur 最后子页面与活动会话编号：切到 Hollow／Love／Roost 再点 Murmur，会回到渡口；刷新也会恢复当前位置。只有渡口左上角返回箭头会把 Murmur 默认入口改回 API 聊天。恢复时先等待后端确认 thread；模型与推理强度来自后端的 thread 恢复响应，不从本机缓存或聊天自述推断。「待下一轮应用」与已确认模型分开显示。浏览器存储不可用时无法保证刷新后的页面恢复。

已完整结束的 Codex 助手消息提供与 Murmur 共用的小喇叭：点击合成并播放，再点暂停／继续；加载时可取消，失败可重试。仍在流式生成或中断的残缺消息不启用朗读。沿用 Murmur TTS 的前 500 字清洗与朗读限制，不会创建 Codex Turn；朗读本身使用现有 TTS 服务。切换会话、离开页面、断线或停止任务时清理音频及未完成的合成请求。

所有原有工具入口保留。「语音通话 → 前往 Murmur」进入原 API 通话入口，需要再点击「拨打 Murmur 通话」才发起通话；取消或通话结束可返回刚才的渡口会话。使用的是 Murmur 的 API 对话内容，不是 Codex 原生通话，也不会把渡口消息伪装成 API 会话。

## 安全与范围

开发回归：`cd yanji-src && npm test`；首次浏览器测试先运行 `npx playwright install chromium`，再运行 `npm run test:browser`。浏览器测试启动本机 Vite，拦截全部外部 HTTP／WebSocket，TTS 与流式回复均为 fixture；不消耗模型或语音服务额度。覆盖组件重挂载、刷新、重连、底部导航、8 个主题的小屏与键盘可视区域、朗读取消及通话入口返回。不能替代真实 Android 键盘与音频权限的最终验收。

- 渡口通过既有言叽连接鉴权进入独立的 `crossing/*` WebSocket namespace，不能读取归巢聊天广播。
- Codex 登录状态、cookie、OAuth token 和其他认证文件都只由服务器本机的 Codex App Server 使用，浏览器和构建产物不接收它们。
- 第一阶段只允许 Codex 成为活动 Agent。未来若支持 Claude Code，必须在服务端显式互斥切换，绝不能同时运行两个 Agent。
- 每个 bridge 实例同时最多一个活动 Codex turn；浏览器断线不会让旧授权作用到新任务。

## 上线前提

部署 bridge 后，App Server 使用服务器已有的 `codex app-server --stdio`。本机已验证的 CLI 版本为 `0.153.4`；上线前应确认目标主机的该命令可完成 `initialize`、`initialized` 和 `account/rateLimits/read` 握手。无需增加前端 API key 或 Codex 凭据。
