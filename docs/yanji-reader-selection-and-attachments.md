# 阅读选区与渡口附件修复 · 2026-09-22

正文下半屏选字时，书摘/批注操作条移到阅读器顶部；上半屏选字时仍放底部。选区消失或离开正文立即清除操作条，保留显式取消入口。操作条按下时保留选区，批注及卡片编辑期间锁定已选内容。阅读器工具栏不再参与原生文字选择。

渡口历史此前把所有非文本输入替换成「图片附件」。现在在已授权的会话读取中投影图片数据与文本文件卡片；只读取当前工作目录上传区内、格式合法的文件名，拒绝其他路径及符号链接。发送时把附件留存在忽略 Git 的上传区 history 子目录，原临时区仍按原 TTL 清理。图片生成最长边 640px 的 JPEG 预览（动图预览为静帧），原文件保留；历史加载使用预览减少传输体积。历史中的内嵌表情图片也可显示。

旧上传原文件已被清理的附件无法恢复，显示不可用说明。附件存档占服务器磁盘空间，当前不自动删除历史存档；未来大量使用时应增加配额与用户管理入口。未增加模型请求或向模型重复发送历史图片。

测试使用临时目录和虚构文件验证发送后存档、临时过期、重启恢复以及路径隔离，未使用生产数据。
