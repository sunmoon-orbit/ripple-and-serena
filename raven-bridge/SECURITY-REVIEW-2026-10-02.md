# 后端重点入口审查 · 2026-10-02

范围：归巢 HTTP/WS、上传回看和下载、链接预览、圆桌投递/恢复、渡口审批。静态检查另覆盖 moon-memory 隔离副本的 Bearer 鉴权、路由挂载和文件下投接口；副本与线上不一致，不构成对线上 moon-memory 的完整结论。本次未修改 moon-memory 的已有工作区改动，未读取真实记忆或凭据做攻击测试。

## 本次修复

- 圆桌附件接受任意 URL，前端会追加登录 token：入站生成本站上传地址，历史回放也过滤旧记录，防止 token 被发往第三方。
- 上传回看允许 HTML/SVG 在归巢源下执行脚本：添加 CSP sandbox 和 nosniff；拒绝目录和符号链接，处理文件流异常。
- 公开下载入口的畸形百分号编码可导致未捕获异常：在 HTTP 分发前校验编码及控制字符，返回 400。普通快捷回复错误 text 类型改为校验失败，避免调用非字符串 trim。
- 已登录 WS 的圆桌操作及终端审批只检查初始认证：逐次校验 token 的有效期/撤销状态；WS 单帧上限降至 1 MiB。
- 链接预览 IPv6 私网识别漏过十六进制 IPv4 映射及扩展地址：规范化并拒绝非公网及转换地址，保留 DNS pinning；预览缓存上限 200。
- 圆桌恢复找不到指定 turn 时会退回线程最后一轮：必须精确匹配已完成 turn，并排除带 commentary phase 的中间输出。
- turn/start 超时会回队重跑、带图失败会自动再启动一次：外部调用前持久标记不确定状态，失败保留 blocked，避免副作用重复执行。需要核对后再重试，不保证外部执行 exactly-once。
- 进程离线后残留审批卡、历史订阅错误没有被本层捕获：主动清理并广播失效审批；等待订阅 promise，让错误回到 roundtable/error。

## 验证与限制

采用临时文件和模拟运行时验证，不向生产聊天写测试消息，不发送真实推送。已有 bridge 测试全量串行运行通过，新增安全与异常恢复回归通过。
