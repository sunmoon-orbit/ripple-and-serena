怎么填
  1. 浏览器打开 github.com/sunmoon-orbit/ripple-and-serena，登录你的号
  2. 点上面的 Settings（手机上可能要点「…」或者切成桌面版才看得到）
  3. 左边找 Secrets and variables → Actions
  4. 点 New repository secret
  5. Name 填：ROOST_BUILD_KEY
  6. Secret 里粘贴上面复制的那串，点 Add secret
填好回归巢说一声，剩下的我来。哪一步找不到就截图给我。
